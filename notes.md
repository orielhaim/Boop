# Marmot rewrite progress

- Branch `marmot-messaging`. The Android and iOS builds use MarmotKit 0.18.0 at source commit `34646a577807f2b112ee031f3c164ec58aa18b64`. The mobile archive hashes are checked by `scripts/fetch-marmotkit.ts`.
- MarmotKit is the only persistent message engine. Removed the NIP-17 runtime, repositories, old attachment encryption and tables. SQLite baseline v2 checks compatibility before opening SecureStore. Call signaling still uses NDK with NIP-44/NIP-59 kind 24880. Group-originated calls consult native membership and use the same direct signaling.
- Chat Kit uses prepared native list, conversation, attention and group state windows. Native updates send row deltas. MDK provides direct and group chat, admin mutations, retention, poll, edit history, search, drafts, send state, linking and opt-in backup. Boop keeps local pins, visibility, translation and drand data.
- Android debug builds passed. The instrumentation test passed direct Welcome and message round trips, edits/replies/reactions, custom event projection, native account reopen and post-restart delivery, group admin changes and removal using the upstream Rust MockRelay fixture. The earlier Bun fixture could not reproduce post-restart delivery and was replaced. A separate run with `https://nostr.download` passed v2 upload, receiver `NOT_REQUESTED` state, explicit download and validation.
- Device pairing succeeded in an Android test, but immediate removal was refused while the roster update settled. The fixture now waits for that state and a rerun is needed. Run the updated builds and checks after current window and settings changes.
- Still verify the final JS/native UI path, captured attachment network behavior, optional backup/restore, group avatars, group lifecycle edge cases and physical-device WebRTC. An iOS build host was unavailable in this environment. Do not claim those checks passed.
