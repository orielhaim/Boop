# Marmot rewrite progress

- Branch `marmot-messaging`. The Android and iOS builds use MarmotKit 0.18.0 at source commit `34646a577807f2b112ee031f3c164ec58aa18b64`. The mobile archive hashes are checked by `scripts/fetch-marmotkit.ts`.
- MarmotKit is the only persistent message engine. Removed the NIP-17 runtime, repositories, old attachment encryption and tables. SQLite baseline v2 checks compatibility before opening SecureStore. Call signaling still uses NDK with NIP-44/NIP-59 kind 24880. Group-originated calls consult native membership and use the same direct signaling.
- Chat Kit uses prepared native list, conversation, attention and group state windows. Native updates send row deltas. MDK provides direct and group chat, admin mutations, retention, poll, edit history, search, drafts, send state, linking and opt-in backup. Boop keeps local pins, visibility, translation and drand data.
- Android x86_64 debug and Hermes export passed. Relay instrumentation exercised direct Welcome, bidirectional text, edits, replies, reactions, native database reopen, offline delivery, bounded window deltas, group invitations, late member addition, admin changes, competing updates, removal, leave, disband, polls, reports, device pairing and device removal.
- The Blossom integration used synthetic data to exercise encrypted group images and v2 attachments. The recipient stayed in `NOT_REQUESTED` before Download, and MDK verified and retained the file after the explicit request.
- A first-contact voice call between independent fresh Android emulator identities rang, was answered, and reached the connected timer on both ends. A separate local TLS relay fixture verified first-contact signaling, encrypted RTC replies, and replay suppression with Marmot stopped.
- Group invitee checks use MDK's non-consuming prewarm command. Group mention composition uses the authenticated member roster. The Android relay test confirmed MDK attaches the intended account tag to the decrypted recipient event. The fixture did not observe a separate unread-mention count in the SDK's direct chat-list read.
- Two Android development builds passed public-relay direct chat creation, explicit Welcome acceptance, and delivery into the recipient's Chat Kit timeline. The test exposed a split discovery path. Kind 10050 was visible on the discovery relay while kind 30443 was on the general relays. The MarmotKit constructor now receives both enabled relay sets for its directory lookups.
- Still open: remote call discovery and self-join for uninvited group members and custom emoji images. Still to verify: an iOS native build, backup archive and restore, real-device recording and conference regression, full Open Later UI unlock, network-level attachment tracing and extended memory profiling.
